# Glosario 

---

### 1. Algoritmo
* **Definición:** Conjunto ordenado, finito y preciso de instrucciones lógicas que permite resolver un problema o realizar una tarea paso a paso
* **Ejemplo:** Seguir los pasos de una receta de cocina

### 2. Programa
* **Definición:** Conjunto de instrucciones diseñadas para que una computadora realice tareas específicas
* **Ejemplo:** Google Chrome

### 3. Código Fuente
* **Definición:** Conjunto de instrucciones escritas en un lenguaje de programación que dictan cómo debe comportarse un programa
* **Ejemplo:** Las líneas de un código en Python como print("Hola, mundo")

### 4. Lenguaje de Programación
* **Definición:** Conjunto de instrucciones que le indican a la computadora qué hacer.
* **Ejemplo:** Python, JavaScript o C++.

### 5. Sintaxis
* **Definición:** Conjunto de reglas gramaticales y estructurales de un lenguaje de programación que determinan cómo deben combinarse los símbolos, palabras y signos para que el código sea válido para el compilador o intérprete.
* **Ejemplo:** En muchos lenguajes es obligatorio cerrar las instrucciones con un punto y coma (`;`) o utilizar llaves (`{}`) para delimitar bloques de código.

### 6. Variable
* **Definición:** Símbolo o característica que puede cambiar y tomar diferentes valores según la situación.
* **Ejemplo:** Un nombre o un número.

### 7. Constante
* **Definición:** Elemento que, a diferencia de la variable, no puede cambiar su valor durante la ejecución del programa.
* **Ejemplo:** Números enteros o decimales (5, -3, 2.5), el número Pi (3.1416) o el número de Euler (2.718).

### 8. Tipo de Dato
* **Definición:** Clasificación que indica al programa qué clase de valor va a almacenar una variable o expresión, determinando el espacio de memoria que ocupará y las operaciones que se pueden realizar con él.
* **Ejemplo:** Datos numéricos enteros (int), cadenas de texto (string) o valores lógicos de verdadero/falso (boolean).

### 9. Operador
* **Definición:** Símbolo especial que indica al compilador o intérprete que debe realizar una operación matemática, lógica o de comparación entre uno o más valores.
* **Ejemplo:** `+`, `-`, `<=`, `>=`, etc.

### 10. Expresión
* **Definición:** Combinación válida de variables, constantes, operadores y llamadas a funciones que el programa evalúa para producir un nuevo valor resultante.
* **Ejemplo:** La operación matemática `(base * altura) / 2` para calcular el área de un triángulo.

### 11. Condicional
* **Definición:** Herramienta en programación que permite ejecutar diferentes instrucciones dependiendo de si una condición lógica es verdadera o falsa.
* **Ejemplo:** (`if`) verdadero (`else`) falso
  

### 12. Bucle
* **Definición:** Construcción de programación que permite repetir un conjunto de instrucciones varias veces.
* **Ejemplo:** Un ciclo que imprima los números del 1 al 10 en la consola utilizando una sola instrucción repetitiva.

### 13. Función
* **Definición:** Bloque de código reutilizable que establece reglas para procesar datos de entrada y devolver un resultado específico.
* **Ejemplo:** Una función llamada `calcularIVA(precio)` que recibe el costo de un producto y devuelve el monto total con impuesto incluido.

### 14. Parámetro
* **Definición:** Valor de entrada que recibe una función o un sistema para operar y producir un resultado específico.
* **Ejemplo:** En la función `saludar(nombre)`, la palabra `nombre` actúa como parámetro que recibirá el valor específico al momento de ejecutar la función.

### 15. Argumento
* **Definición:** Dato específico que se le envía a una función o comando para personalizar su comportamiento.
* **Ejemplo:** Al ejecutar `saludar("Sofía")`, el texto `"Sofía"` es el argumento pasado a la función.

### 16. Retorno
* **Definición:** Resultado o valor que una función o método entrega de vuelta al lugar donde fue llamado.
* **Ejemplo:** El resultado numérico `15` que una función de suma devuelve tras procesar los números `7` y `8`.

### 17. Arreglo
* **Definición:** Estructura de datos lineal que permite almacenar una colección ordenada de elementos del mismo tipo bajo un mismo nombre, accediendo a ellos mediante un índice numérico.
* **Ejemplo:** Una lista de compras almacenada en una sola variable: `["manzanas", "leche", "pan", "huevos"]`.

### 18. Objeto
* **Definición:** Entidad dentro de la programación orientada a objetos que agrupa tanto características (atributos o propiedades) como comportamientos (métodos) relacionados entre sí.
* **Ejemplo:** Un objeto llamado `coche` que tiene atributos como `color` y `marca`, y métodos como `acelerar` y `frenar`.

### 19. Método
* **Definición:** Función específica que pertenece a un objeto o clase y define las acciones o comportamientos que dicho objeto puede realizar.
* **Ejemplo:** La acción `reproducir()` dentro de un objeto de tipo reproductor de música.

### 20. Evento
* **Definición:** Acción o suceso que ocurre en el sistema (como un clic del mouse, presionar una tecla o la carga de una página web) al cual un programa puede responder ejecutando un bloque de código.
* **Ejemplo:** La acción de hacer clic en un botón digital que activa una ventana emergente de confirmación en una aplicación.

### 21. Compilador
* **Definición:** Tipo de programa informático que convierte código de un lenguaje de programación (el lenguaje de origen) a otro lenguaje de programación (el lenguaje de destino).
* **Ejemplo:** TypeScript, Swift.

### 22. Intérprete
* **Definición:** Herramienta para lenguajes interpretados que ejecuta el código directamente, sin necesidad de compilarlo previamente, procesando las instrucciones línea por línea.
* **Ejemplo:** Python, JavaScript, Ruby, PHP.

### 23. Depurador (Debugger)
* **Definición:** Herramienta utilizada en el proceso de encontrar, aislar y resolver errores de programación conocidos como *bugs* en programas de software.
* **Ejemplo:** GDB (GNU Debugger), LLDB, Visual Studio Debugger.

### 24. IDE (Entorno de Desarrollo Integrado)
* **Definición:** Aplicación de software que ayuda a los programadores a desarrollar código de software de manera eficiente al integrar editores, depuradores y herramientas en una sola interfaz.
* **Ejemplo:** Visual Studio Code (VS Code), IntelliJ IDEA, Eclipse, PyCharm.

### 25. Editor de Código
* **Definición:** Herramienta de software que permite escribir y editar código fuente de programas, incluido HTML.
* **Ejemplo:** Sublime Text, Visual Studio Code (VS Code), Atom, Notepad++, Brackets.

### 26. Librería (Library)
* **Definición:** Colección de código desarrollado previamente que los programadores pueden utilizar para desarrollar software de manera más ágil.
* **Ejemplo:** NumPy, Matplotlib, TensorFlow, jQuery, p5.js, Polymer, Dojo Toolkit.

### 27. Framework
* **Definición:** Esquema o marco de trabajo que ofrece una estructura base para elaborar un proyecto con objetivos específicos, funcionando como punto de partida para el desarrollo de software.
* **Ejemplo:** Laravel (PHP), React (JavaScript), Django (Python).

### 28. API (Interfaz de Programación de Aplicaciones)
* **Definición:** Conjunto de reglas o protocolos que permiten que las aplicaciones de software se comuniquen entre sí para intercambiar datos, características y funcionalidades.
* **Ejemplo:** Google Maps API, Weather API, Skyscanner API.

### 29. Repositorio
* **Definición:** Ubicación central en la que se puede almacenar, organizar y gestionar código, datos y otros archivos relacionados con un proyecto.
* **Ejemplo:** Repositorios digitales e institucionales como Kérwá, SciELO.

### 30. Control de Versiones
* **Definición:** Proceso sistemático de seguimiento y gestión de actualizaciones del código fuente y los recursos de software.
* **Ejemplo:** Git, Subversion (SVN), Mercurial, CVS.

### 31. Git
* **Definición:** Sistema de control de versiones distribuido, gratuito y de código abierto que facilita la colaboración y la coordinación entre desarrolladores.
* **Ejemplo:** Comandos como `git init`, `git clone`.

### 32. GitHub
* **Definición:** Plataforma de desarrollo colaborativo que aloja proyectos en la nube utilizando el sistema de control de versiones Git.
* **Ejemplo:** Alojamiento de proyectos de aplicaciones web/móviles, documentación abierta y automatizaciones.

### 33. Rama (Branch)
* **Definición:** Línea de desarrollo independiente dentro de un repositorio que permite trabajar en nuevas funcionalidades o corregir errores sin afectar el código principal.
* **Ejemplo:** `feature/login-google`, comando `git branch feature/nuevo-menu.

### 34. Commit
* **Definición:** Acto de guardar los cambios realizados en un proyecto de software dentro del sistema de control de versiones mediante una instantánea del estado del código.
* **Ejemplo:** `git commit -m "feat: añadir soporte para autenticación con Google".

### 35. Merge
* **Definición:** Proceso de combinar dos o más conjuntos de datos, ramas de código o estructuras en una sola.
* **Ejemplo:** Combinar los cambios de una rama secundaria (`feature`) en la rama principal (`main`) ejecutando `git merge feature.

### 36. Callback
* **Definición:** Función que se pasa como argumento a otra función para que sea ejecutada (llamada) después de que se complete cierta tarea o evento.
* **Ejemplo:**
  ```javascript
  boton.addEventListener('click', function() {
      console.log("Botón clickeado");
  });
  

### 37. Programación Sincrónica
* **Definición:** Modelo de ejecución lineal y secuencial en donde cada tarea debe completarse obligatoriamente antes de que comience la siguiente.
* **Ejemplo:** Sistemas de transacciones financieras o procesamiento de datos por lotes.

### 38. Programación Asincrónica
* **Definición:** Modelo de programación que permite que múltiples tareas se ejecuten de forma independiente y simultánea, garantizando que las operaciones lentas no bloqueen la ejecución del programa.
* **Ejemplo:** Aplicaciones de chat en vivo o análisis de datos en tiempo real.

### 39. JavaScript
* **Definición:** Lenguaje de programación o de secuencias de comandos interpretado que permite implementar funciones complejas e interactivas en páginas web.
* **Ejemplo:**
  ```javascript
  const nombre = "Ana"; // String
  let edad = 25;       // Número
  const esEstudiante = true; // Booleano
  

### 40. TypeScript
* **Definición:** Lenguaje de programación de tipado estricto basado en JavaScript que permite detectar errores en tiempo de desarrollo y se compila a JavaScript estándar.
* **Ejemplo:**
  ```typescript
  let nombre: string = "Ana";
  let edad: number = 30;
  let activo: boolean = true;
